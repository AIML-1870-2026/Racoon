Error Reference

Understanding and resolving common API errors

🚫 CORS Limitations

CORS_BLOCKED -
Request Blocked
The request was blocked by the browser's CORS policy. This is a browser security feature, not an error with your API key.

What is CORS?

CORS (Cross-Origin Resource Sharing) is a browser security mechanism that restricts web pages from making HTTP requests to a domain different from the one that served the page. When this app tries to call an API on a different domain, the browser enforces CORS rules.

Why does it block the request?

Before sending the actual API call, the browser sends a preflight OPTIONS request asking: "Do you allow requests from this origin?" The API server must respond with headers like:

Access-Control-Allow-Origin: * Access-Control-Allow-Headers: Authorization, Content-Type

If the server doesn't include these headers, the browser blocks the request entirely - even if your API key is correct.

Which providers are affected?

Provider Browser-Direct Calls Notes
Anthropic Blocked Requires a backend proxy
OpenAI Blocked No CORS support for browser requests
Google Gemini Partial Some endpoints may work; behavior varies
Mistral Blocked Backend-only API
Meta (Groq/Together) Varies Depends on hosting provider's CORS policy

How to resolve CORS issues

Option 1: Proxy Mode (Recommended)

Route all API requests through a lightweight backend proxy server. Configure the proxy URL in Settings. The proxy forwards requests to the provider and returns responses to your browser.

Option 2: Local Proxy / Desktop Mode

If running locally, some providers permit requests from localhost origins. A local proxy (Express, FastAPI, etc.) on the same machine can forward requests without triggering CORS.

Security Warning: When using a proxy, ensure it is a server you control. Never route your API keys through a third-party proxy service you do not trust, as the proxy can read your keys and request payloads.

🔒 Authentication Errors

AUTH_INVALID_KEY HTTP 401
Invalid API Key
The key provided for the selected provider was rejected. This typically means the API key is incorrect, has been revoked, or was never valid.
Resolution: Double-check that you've copied the complete API key from your provider's dashboard. Ensure there are no extra spaces. If the key was recently created, wait a few minutes and try again.
AUTH_INSUFFICIENT_PERMISSIONS HTTP 403
Access Denied
Your API key does not have permission to use this model or endpoint. Some models require specific access tiers or permissions.
Resolution: Check your account's tier or feature access at the provider's dashboard. Some models (like GPT-4, Claude Opus) may require paid plans or explicit access grants.

⏳ Rate Limiting & Quota Errors

RATE_LIMIT_REQUESTS HTTP 429
Too Many Requests
You've exceeded the request rate limit for the provider. Each provider has limits on how many requests you can make per minute.
Resolution: Wait a moment before retrying. Consider reducing request frequency or implementing request queuing in your workflow.
RATE_LIMIT_TOKENS HTTP 429
Token Quota Exceeded
You've hit the per-minute token limit. This is separate from request limits and applies to the total tokens processed.
Resolution: Try reducing Max Tokens or simplify your prompt. Wait for your token quota to reset (usually per minute).
QUOTA_EXHAUSTED HTTP 402
Account Quota Exhausted
Your account has no remaining credits or has hit its monthly usage cap.
Resolution: Add credits to your account or upgrade your plan at the provider's billing page.

⚠ Request Errors

INVALID_REQUEST_BODY HTTP 400
Bad Request
The request was malformed. This may be caused by an invalid schema, an unsupported parameter for this model, or a missing required field.
Resolution: Check your custom schema for JSON syntax errors. Ensure all required fields are provided. Some parameters may not be supported by all models.
CONTEXT_LENGTH_EXCEEDED HTTP 400
Prompt Too Long
Your prompt exceeds the context window for the selected model. Each model has a maximum number of tokens it can process.
Resolution: Shorten your input text or switch to a model with a larger context window (e.g., Gemini 2.5 Pro with 1M tokens, or Claude with 200K tokens).
INVALID_MODEL HTTP 400
Unknown Model
The selected model ID is not recognized by the provider. The model may have been deprecated or the ID is incorrect.
Resolution: Check that the model ID is spelled correctly. For custom providers, verify the model name matches what the API expects.
SCHEMA_PARSE_FAILURE HTTP 422
Response Parse Error
The model returned a response that could not be parsed as valid JSON. This happens when using structured output mode but the model doesn't return valid JSON.
Resolution: Try adjusting your schema or adding stricter formatting instructions in your system prompt. Some models follow JSON schemas more reliably than others.

🌐 Server & Network Errors

PROVIDER_SERVER_ERROR HTTP 500
Provider Error
The provider's API returned an internal server error. This is not caused by your request.
Resolution: Wait a few moments and retry. Check the provider's status page for any ongoing incidents.
PROVIDER_UNAVAILABLE HTTP 503
Service Unavailable
The provider is temporarily unavailable or undergoing maintenance.
Resolution: Check the provider's status page and retry shortly. Consider using a different provider temporarily.
NETWORK_TIMEOUT -
Request Timed Out
No response was received within the configured timeout period.
Resolution: Check your internet connection. You can increase the timeout in Settings. For long prompts, consider reducing Max Tokens.
NETWORK_OFFLINE -
No Internet Connection
Your device appears to be offline.
Resolution: Restore your internet connection and retry.

🛠 Application Errors

NO_API_KEY -
No API Key Set
You haven't entered an API key for the selected provider.
Resolution: Add your API key in the API Keys panel. You can get keys from each provider's developer console.
NO_MODEL_SELECTED -
No Model Selected
Please select a model before sending your request.
Resolution: Choose a provider and model from the Model Selection panel.
EMPTY_PROMPT -
Prompt is Empty
The User Message field cannot be blank.
Resolution: Enter your prompt in the User Message field, or select an example prompt to get started.
INVALID_JSON_SCHEMA -
Invalid Schema
Your custom schema contains a JSON syntax error.
Resolution: Check the schema editor for highlighted errors. Ensure proper JSON formatting with matching brackets and quotes.
